# 비전공자용 용어 대응표

비전공자 독자 문서에서 기술 용어를 바꿀 때 쓴다. "일상어"를 기본으로 쓰고,
화면에 용어가 그대로 나와서 꼭 써야 하면 "처음 한 번 풀어 쓰기" 형태를 쓴다.

## 제품·에이전트

| 기술 용어 | 일상어 | 처음 한 번 풀어 쓰기 |
|-----------|--------|---------------------|
| 에이전트 (Agent) | 업무를 맡길 수 있는 AI 담당자 | 에이전트(정해진 업무를 대신 처리하는 AI) |
| Agent Builder | 에이전트를 만드는 화면 | Agent Builder(대화로 AI 담당자를 만드는 화면) |
| 자연어 빌더 / 컴포저 | 말로 설명하면 만들어 주는 기능 | — |
| 프롬프트 / 지침 | AI에게 주는 업무 지시서 | 프롬프트(AI에게 주는 업무 지시문) |
| 도구 (Tool) | AI가 쓸 수 있는 기능 (메일 보내기, 문의 조회 등) | — |
| MCP / MCP 서버 | 사내 시스템 연결 | MCP(사내 시스템과 AI를 잇는 연결 통로) |
| 스킬 | 미리 만들어 둔 업무 요령 | — |
| 멀티 에이전트 / supervisor / worker | 여러 AI가 일을 나눠 처리 | — |
| 서브에이전트 | 일부 업무를 맡는 보조 AI | — |
| 스케줄 / cron | 정해진 시간에 자동 실행 | — |
| 웹훅 | 다른 시스템에 결과 자동 알림 | — |
| 백그라운드 잡 | 화면을 닫아도 뒤에서 계속 처리 | — |
