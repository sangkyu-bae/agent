# /ingredients

프로젝트(Agent Builder)의 **소개 글 재료 전집**을 뽑아 `docs/intro/ingredients/<YYYY-MM-DD>.md` 한 파일로 만든다.
무엇을 만들었고, 왜 그렇게 판단했고, 무엇을 버렸는지를 모듈·설계 판단·기획·협업·실패 단위로 근거 경로와 함께 길게 서술한다.

특정 회사용 글이 아니다. 회사마다 공고가 다르므로, 자기소개서·포트폴리오는 이 문서에서 재료를 골라
`project-story`(내용 선택) → `doc-writer`(구조) → `plain-tone`(어투) 순서로 조립한다.

실제 작업은 `ingredients-extractor` 서브에이전트(`.claude/agents/ingredients-extractor.md`)가 수행한다.

## 사용법
```
/ingredients [--months 2026-07,2026-08] [--note "부가 지시"]
```

예시:
```
/ingredients
/ingredients --note "MCP·보안 쪽 판단 이유를 특히 자세히"
/ingredients --months 2026-09,2026-10 --note "최근 두 달만 다시 뽑기"
```

## 실행 순서

### 1. 인자 파싱

- `--months` 기본은 `idt/docs/archive/` 아래 전체 월. 주어지면 그 월만 읽는다(다른 소스는 그대로 전부 읽는다).
- `--note` 기본 없음.
- 오늘 날짜(`YYYY-MM-DD`)를 확정한다. 같은 날짜 파일이 이미 있으면 덮어쓴다고 사용자에게 한 줄 알린다.

### 2. 에이전트 스폰

`Agent` 도구로 `ingredients-extractor`를 스폰한다. **직접 문서를 쓰지 않는다.**
프롬프트에 아래를 그대로 담는다(에이전트는 이 대화를 볼 수 없다):

```
오늘 날짜: <date>
범위(months): <months 또는 "전체">
부가 지시: <note 또는 "없음">
이번 세션에서 알게 된 관련 사실: <있으면 요약, 없으면 "없음">
```

아카이브 전체를 읽으므로 시간이 걸린다. 끝날 때까지 기다린다.

### 3. 결과 전달

에이전트 보고(산출물 경로, 절별 분량, 묶은 모듈 목록, 판단 이유 미기록 카드, 확인 필요)를 사용자에게 그대로 전달하고 아래를 안내한다.

- 재료 위치: `docs/intro/ingredients/<date>.md`
- 자소서를 쓸 때: 공고 키워드를 §10 지도에서 찾아 해당 카드를 꺼낸 뒤 `/doc-writer 채용 <공고 파일>` 로 조립
- §11 부록의 작업량 수치는 소개 글에 쓰지 않는다

### 4. 후속 (사용자가 요청할 때만)

- "n번 카드 보강해줘" → 같은 파일을 직접 Edit (에이전트 재스폰 불필요)
- "다시 뽑아줘" → 새 날짜 파일로 에이전트 재스폰 (기존 파일은 유지)

## 하지 않는 것

- 커밋·푸시 (원하면 `/commit`)
- 회사별 자소서·포트폴리오 작성 (그건 `/doc-writer`)
- `docs/intro/` 안의 포트폴리오·덱·자소서 수정
